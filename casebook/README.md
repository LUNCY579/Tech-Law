**Important:** An official primary source is not a substitute for verifying its latest amendments, judicial treatment, implementing rules, state-specific variations or whether the hypothetical company is regulated. The Supreme Court syllabus is expressly *not* part of the opinion: read the majority/dissent and use page pinpoints from those portions for citations. Opinions are linked, not reprinted. No unofficial report is presented as an authenticated court original.
